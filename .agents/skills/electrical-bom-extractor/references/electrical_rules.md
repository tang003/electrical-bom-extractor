# 工业电气原理图符号、位号规范与 BOM 归并准则

## 1. 常见位号（设备标识符）与元器件分类

| 位号前缀 | 典型名称 | 采购统计规则 |
| :--- | :--- | :--- |
| `-QF` / `-F` | 断路器 / 马达保护断路器 | 按主触点位号统计；若控制回路出现同序号 `-FR` 或 `/7.2:B 1C/O` 辅助触点，需追加辅助触点模块（如 `+GVAE11` 或 `iOF A9A26904`）。 |
| `-KM` | 交流接触器 | 跨页合并主触点(`1-2, 3-4, 5-6`)、线圈(`A1-A2`)与辅助触点(`13-14, 21-22`)为 1 个物理接触器。注意星三角启动中 `-KM1`(主)、`-KM1-2`(△)、`-KM1-1`(Y) 是 3 个独立接触器，不可合并为 1 个。 |
| `FR` / `-FR` | 热过载继电器 | 主回路热元件(`FR1`)与控制回路常闭/常开触点(`-FR1`)合并为 1 个物理热继电器。 |
| `-KA` / `-K` | 中间继电器 | 按线圈(`A1-A2`)唯一位号统计物理数量，分散在各页的常开/常闭触点不重复计数；通常需配继电器底座(`RXZE*`)及保护插件(`RXM040W`)。 |
| `-KT` | 时间继电器 | 合并线圈与延时触点，注意检查底座型号。 |
| `HL` / `-H` | 指示灯 / 声光报警 | 按唯一位号与颜色标注（红/绿/黄/白）分类统计。 |
| `-SB` / `-S` / `-ES` | 按钮 / 急停开关 / 温控开关 | 按唯一位号统计，急停按钮常配保护罩(`ZB2BZ1605C`)。 |
| `-SA` | 旋转选择开关 | 区分二位旋钮(`XB2BD21C`)与三位旋钮(`XB2BD31C`)；若同一位号跨页标出不同型号需触发冲突审核。 |
| `-X` / `=+-X` | 接线端子排 | `-X1:1~30` 中的每个端子号代表端子排上的 1 个端子片，不能按独立电气主器件统计，应按回路线径/电流归类统计端子数量。 |
| `Q11` / `101` / `201` | 导线编号（线号） | 严禁作为元器件计入 BOM。 |

## 2. 图纸明文物料 vs 工程推导物料的区分

所有输出的 BOM 行必须标注 `source_type`：
1. `EXPLICIT`（原图明文）：图纸上直接写出位号与完整型号。
2. `TOPOLOGY_INFERRED`（拓扑推导）：同功率对称电机回路（如 1#、2# 45KW 主泵）省略重复标注时，由主回路结构与控制回路交叉推导。
3. `RULE_COMPLETED`（规则补全）：根据同图已明确的系列（如施耐德 `XB2`）或 PLC 必配附件规则（如 `S7-1500` 前连接器/导轨/存储卡）自动补全。
4. `ESTIMATED_AUX`（工程估算）：柜体、导线、端子、人工等成套辅材。
5. `MANUAL_EDITED`（人工已改）：工程师在 Web 审核台手动确认或修改后的记录。
